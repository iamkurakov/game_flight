# LA Flight Simulator

3D-симулятор лёгкого винтового самолёта над стилизованным Лос-Анджелесом.
Чистый JavaScript + Three.js r128 (лежит в `libs/`), без сборки и внешних зависимостей — работает офлайн.

**Играть:** `https://<ваш-логин>.github.io/<имя-репозитория>/`

## Что внутри
- взлёт с полосы, свободный полёт, посадка, аварии и мгновенный рестарт;
- миссия «Обзорный полёт»: 6 колец и посадка в аэропорту;
- Даунтаун, Голливудские холмы, знак HOLLYWOOD, обсерватория Гриффита, пирс Санта-Моники, аэропорт;
- камеры: сзади, из кабины, кинематографическая; звук на Web Audio; интерфейс RU/EN.

Карта стилизованная: дороги, здания и ориентиры схематичны, не географически точны.

## Управление
| Клавиши | Действие |
|---|---|
| W / S | тангаж вниз / вверх |
| A / D | крен влево / вправо |
| Q / E | руль направления |
| Shift / Ctrl (или X / Z) | газ больше / меньше |
| Space | тормоза колёс |
| C | камера |
| R | рестарт |
| P / Esc | пауза |
| F3 | отладка |
| M T U G L I | звук · помощник · единицы · тени · язык · инверсия тангажа |

Стрелки работают как W A S D. Ctrl+W закрывает вкладку — для газа вниз используйте Z.

### Телефон и планшет
Держите устройство горизонтально. При нажатии «Start Flight» игра переходит в полноэкранный режим, а iOS спрашивает доступ к датчику движения — разрешите.
- наклон как у руля — крен; верхний край от себя / к себе — снижение / набор высоты;
- нейтраль по тангажу запоминается в момент старта; кнопка **НОЛЬ** перекалибрует её;
- газ — ползунок слева, **ТОРМОЗ** — удерживать, **Камера**, **II** — пауза;
- если датчик наклона недоступен — водите пальцем по экрану как джойстиком.

Датчики наклона работают только по HTTPS (GitHub Pages подходит).

## Запуск локально
    python -m http.server 8000
    # открыть http://localhost:8000

Единый автономный файл: `python build.py la-flight-sim.html`

## Структура
    index.html, styles.css, build.py
    libs/three.min.js        Three.js r128 (MIT)
    src/                     модули игры (физика, мир, город, ориентиры, HUD, миссия, звук, камеры)
    tests/                   проверки физики и географии (Node): node tests/phys_test.js

Координаты: X — восток, Z — юг (север = −Z), Y — вверх; метры; курс 0° = север.
